# Каталог дыр

Именованные паттерны с прецедентами. Инспекторы читают его перед работой, чтобы узнавать знакомое,
и пишут «не в каталоге» для нового. Оркестратор после каждой ревизии дописывает новые паттерны
в раздел «Непроверенные»; в «Подтверждённые» они переезжают после проверки причины
подходящими доказательствами. Повторение или решение «лечим» не подтверждает причину. Номер семейства — в скобках.

## Подтверждённые

### Первый контакт (1)
- **Необъяснённое использование.** За 30 дней писал только владелец — сигнал для проверки
  аудитории и стадии запуска, не доказательство незнания команды. Причина требует наблюдений.
  Планировщик v0.26.0; Библиотекарь: users=1, «коллега ещё не заходила».
- **Магическая фраза.** Код узнаёт оборот из речи владельца, справка о нём молчит.
  Планировщик v0.16.1 «Планировщик, спланируем сентябрь?»; «запомни:» → бэклог бота.
- **Нет /help.** Единственная справка — в голове владельца. Планировщик до v0.26; Библиотекарь (`/help` нет).
- **Тихое ожидание.** Долгий вызов без «думаю…», человек не знает, ждать ли. Планировщик v0.19.3, v0.1.2.
- **Кнопка без последствия в подписи.** «ОК» вместо «Применить 3 правки». Планировщик v0.5.1.

### Обещания (2)
- **Обещание в промпте.** Модель говорит «сейчас напишу команде», инструмента нет. Планировщик v0.23.0.
- **Кнопка-статус.** Подпись обещает действие, хендлер меняет только статус. Планировщик «В память» v0.27.0.
- **Ответьте здесь.** Крон-пост зовёт отвечать reply, бот reply не читает. Планировщик утренний пост.
- **Нет успехов при попытках.** Функция есть, попытки были, в журнале 0 успехов.
  При нуле попыток это ограничение наблюдений; сопоставь лог с конечным результатом. Библиотекарь: каскад обложек;
  распознавание молчало неделю. Планировщик: раздел СЕССИИ пуст, WIKI-RULES без дела.
- **Два источника правды.** Промпт исключает бэклог, функция отчёта его считает. Планировщик `find_bottlenecks`.
- **Мёртвая функция за обещанием.** `append_page`, статус `approved`, который никто не читает.

### Доступ, контуры и деньги (3)
- **Проверка только в личке.** В группах любой участник дёргает движок. Планировщик до v0.26.
- **Чужая кнопка.** Callback не сверяет нажавшего. Планировщик «Применить» до v0.26.
- **Утечка контура.** Вопрос из клиентского чата тянет контекст командного; `/summary` в чужой
  группе. Планировщик v0.26.0.
- **Молчаливый фолбэк.** Отказ провайдера уезжает на другой платный счёт без сообщения. Планировщик v0.26.0.
- **Пустая комната.** Платный нотетейкер приходит на несостоявшийся созвон. Планировщик v0.4.1.
- **Гейт не по назначению.** Проверка для зумов переиспользована для планирования. Планировщик.
- **Кэш членства без TTL.** Убрали из чата — всё ещё свой. Планировщик `_member_cache`.
- **Общая очередь.** Фото одного пользователя уезжает в каталог другого. Библиотекарь #2.

### Найдено живым прогоном (Редакция, 07.09.2026)
Подтверждены воспроизведением на проде и повторным прогоном после лечения.
- **Кнопка есть, слова нет.** Намерение распознаётся только кнопкой; та же просьба словами
  уходит движку как задача и жжёт ход. «Новая работа» AA-089, «вернёмся к сценариям» AA-097 (8, 1).
- **Совпадение по подстроке.** Нечёткий матчинг ловит чужое слово («перейди» ≈ «перед») и не
  ловит словоформу («в сценариях» ≠ «Сценарии»). AA-088, AA-097 (8, 4).
- **TODO за обещанием.** Документация обещает автоматику, в коде на её месте TODO; видно только
  при доведении сценария до финала. Петля калибровки AA-102, S1 (2).
- **Отметка без текста невидима.** Правка артефакта без комментария исключена из отпечатка —
  «нечего забирать». AA-090, S1 (6).
- **Рендер склеивает переносы.** Одиночный перенос markdown становится пробелом в rich-сообщении
  и при импорте в Google; строки-тире слипаются в абзац. AA-096, AA-100 (7, 6).
- **Файлы в ответах.** Имена файлов и пути workdir всплывают в реплике и карточке. AA-101 (5, 7).
- **Открытый вопрос не гаснет.** «Где мы» показывает давно отвеченный вопрос. AA-098 (1, 4).
- **Уведомление по роли, а не по решению.** Автокарточка руководителям при публикации, хотя
  редактор — сам автор. AA-095 (3, 2).
- **«Пусто» при одном готовом.** Карточка контейнера говорит «пока пусто», доска — «1 готово». AA-091 (1).
- **Имя из всей фразы.** Название сущности берётся из фразы задания целиком, включая команду. AA-092 (4).
