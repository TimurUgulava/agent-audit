# Задание инспектору

Мишень: {путь}; область: {файлы/компоненты}; сквозные сценарии: {S-id}; ответственный
за каждый путь: {роль}. Боли, критерии приёмки, доступная среда, границы авторизации:
{контекст}. Прочитай карту {map}, открытые находки {ledger}, обещания и артефакты {пути}.

Читай `evidence.md`, `scenarios.md`, `journey-quality.md`, `visual-review.md` и релевантные
семейства 01–08. Все восемь семейств должны быть распределены в общей матрице охвата;
не загружай каждому инспектору весь каталог без необходимости. Исторический прецедент —
подсказка, не доказательство текущей проблемы.

Проследи путь через все компоненты; на границе сообщи ответственному сценария незакрытые
вопросы. Наличие функции не доказывает её выполнение. Для каждой оси укажи критерий,
метод, наблюдение и вердикт. Не называй экспертный проход пользовательским тестом.
Предложи улучшенный путь и пример оформления при существенном замечании, сохраняя содержание.

## Формат находки

```
### [A-01] Повторная попытка может применить действие дважды
тип: технический риск
вердикт: подтверждено
серьёзность: S1 · существенно
оси: техническая надёжность, работоспособность
сценарий: S03; стадии: пройти работу, исправить
история: Участник повторяет запрос после таймаута. Первое действие уже сохранено,
  повтор выполняется заново; участник получает два объекта вместо одного.
последствия: дублирование результата; обход — ручное удаление
охват/частота: каждый повтор после таймаута; частота в проде не измерена
доказательства: code; путь/строки, вход → запись → таймаут → повтор
ожидалось / фактически: одно действие / два
причина: отсутствует проверка ключа повторного запроса
рекомендация: сохранять ключ операции и возвращать ранее созданный результат
приёмка: повтор с тем же ключом после таймаута возвращает тот же объект
неопределённость: воспроизведение не выполнялось; поведение хранилища прослежено по коду
```

Образцы карточек — `examples.md`. Для visual укажи артефакт/снимок и условия просмотра; для reproduction — точные шаги,
среду и результат. Место в коде указывай, если установлено; не выдумывай его ради шаблона.
Для улучшения явно обозначь ожидаемый эффект вместо утверждения о поломке.

Верни одним сообщением краткую сводку и полные карточки всех существенных находок, затем:
«Матрица сценариев», «Проверено без замечаний», «Не проверено», «Вопросы на стыках»,
«Новые паттерны». Квот нет. Если объём не помещается, согласуй разбиение/продолжение,
не теряй существенные находки и не понижай серьёзность из-за номера.
